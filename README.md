# 데이터쿡·인디제이 나라장터 영업 대시보드

GitHub Actions가 나라장터 **발주계획 → 사전규격 → 입찰공고**를 정기 조회하고 `data.json`을 갱신합니다. GitHub Pages는 최신 데이터를 읽어 D-Day와 데이터쿡/인디제이 적합도 우선순위를 표시합니다.

## 자동 수집 대상

1. 조달청_나라장터 **입찰공고정보서비스**
2. 조달청_나라장터 **사전규격정보서비스**
3. 조달청_나라장터 **발주계획현황서비스**

공공데이터포털에서 위 3개 서비스를 각각 `활용신청`해야 합니다. 계정의 인증키가 같더라도 서비스별 승인 여부는 별도입니다.

## GitHub Secret

Repository → Settings → Secrets and variables → Actions → New repository secret

- 이름: `DATA_GO_KR_API_KEY`
- 값: 공공데이터포털 일반 인증키의 **Decoding 키**

키는 HTML/JavaScript에 넣지 않습니다.

## 자동 실행 시간

`.github/workflows/update.yml`에서 하루 3회 실행합니다.

- 08:30 KST
- 13:30 KST
- 18:30 KST

Actions → **Update G2B Sales Dashboard** → **Run workflow**로 수동 실행도 가능합니다.

## 자동 분류

검색 범위는 AI/인공지능/LLM/RAG/Agent/NLP/상담/Voice/데이터셋/학습데이터/영상분석/의료AI/모빌리티/자율주행/산불/재난뿐 아니라 일반 SI, 시스템 구축·고도화, 플랫폼, ISP/ISMP, DB/GIS, 유지관리, 통합관제, 대시보드, 앱/웹, 디지털트윈, 스마트공장·스마트시티 등을 포함합니다.

자동 수집된 건에는 다음 값이 추가됩니다.

- `stage`: 발주계획 / 사전규격 / 본공고
- `dDay`: 의견마감 또는 입찰마감까지 남은 일수
- `datacook`: 데이터쿡 적합도
- `indij`: 인디제이 적합도
- `priority`: S+/S 우선, 마감임박 등
- `priorityScore`: 대시보드 정렬 점수

### 우선순위 표시

- `🔥 S+ 최우선`: 데이터쿡 또는 인디제이 적합도 S+
- `🔥 S 우선`: 데이터쿡 또는 인디제이 적합도 S
- `🟢 선행영업`: 발주계획 단계의 A+ 이상 후보
- `⚠️ 마감임박`: D-7 미만
- `마감`: 마감일 경과

사용자 영업원칙에 맞춰 D-7 미만 신규 공고는 상단 우선추천보다 마감임박 경고를 우선 표시합니다.

## 주의

현재 적합도는 공고/사업 제목 및 API가 제공하는 기본 필드를 바탕으로 한 **1차 자동분류**입니다. 제목에 AI가 없지만 RFP 본문에 AI·RAG·GIS 등이 포함된 사업을 완전히 잡기 위해서는 다음 단계로 RFP 첨부파일 자동 다운로드·본문 분석을 추가하는 것이 좋습니다.
